# Existing Project Inspection

Before modifying anything:

- Inspect the repository structure.
- Identify the existing code, dependencies, configuration files, and documentation.
- Identify the Flutter, Dart, Node.js, Express, and PostgreSQL versions currently in use.
- Review the existing architecture, navigation, state management, and API connections.
- Identify completed, incomplete, and potentially broken features.
- Preserve all working functionality.
- Do not overwrite or restructure existing code without first explaining why the change is necessary.

If application code has not yet been created, plan its initial structure and record approved toolchain versions before generating project files.
