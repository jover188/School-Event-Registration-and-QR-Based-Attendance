# Data, Backend, and Security

Analyze the system's data requirements before implementing database or API functionality.

- Identify required data entities and relationships.
- Document expected API requests and responses.
- Use suitable validation on both the client and server.
- Enforce authentication and authorization on the trusted backend.
- Do not rely on hidden buttons or client-side restrictions for security.
- Never hardcode passwords, tokens, or private API keys.
- Use secure handling for sensitive local data.
- Avoid unnecessary collection or exposure of personal information.
- Handle connection failures, timeouts, and invalid responses.
- Define how duplicate submissions and repeated requests will be handled.
- Consider offline behavior only when required by the approved PRD.
