# Phased Development Workflow

Work in small, manageable phases.

For each phase:

1. Identify the requirements covered.
2. Explain the proposed implementation.
3. List the files likely to be created or modified.
4. Identify dependencies and risks.
5. Implement only the approved scope.
6. Add or update relevant tests.
7. Run applicable checks.
8. Summarize completed work and remaining issues.

Avoid modifying unrelated features.

Do not proceed to another major phase without reviewing the previous phase's results.
