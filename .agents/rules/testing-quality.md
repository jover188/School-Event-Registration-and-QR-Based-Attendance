# Testing and Quality

Every implemented feature must be verified against its approved PRD requirements.

- Create unit tests for important logic.
- Create widget tests for important UI behavior.
- Create integration tests for critical user workflows when practical.
- Test valid, invalid, empty, duplicate, and unexpected inputs.
- Test loading, network failure, and recovery behavior.
- Run formatting, static analysis, and relevant tests.
- Fix errors introduced by the implementation.
- Clearly report any tests that could not be executed.
