# Flutter Development Standards

Follow Flutter and Dart best practices.

- Prefer Flutter's built-in widgets when they satisfy the requirements.
- Use Material Design components unless the project defines another design system.
- Create reusable buttons, text fields, dialogs, navigation components, and other shared UI elements.
- Centralize colors, typography, spacing, and themes.
- Support the screen sizes, orientations, accessibility settings, and operating systems in the approved device test matrix.
- Handle loading, empty, success, and error states.
- Prevent layout overflow and unnecessary widget rebuilding.
- Follow Dart null-safety requirements.
- Dispose of controllers and other resources when necessary.
- Use asynchronous operations correctly to avoid freezing the interface.

Choose state management and navigation solutions only after evaluating the project's requirements.
