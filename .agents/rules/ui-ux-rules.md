# UI/UX Rules

Before implementing screens:

- Identify every screen required by the approved PRD.
- Document navigation paths and user interactions.
- Create a consistent visual design system.
- Use clear labels, readable text, and appropriate spacing.
- Provide useful validation and error messages.
- Support accessibility, including readable contrast and practical touch-target sizes.
- Consider keyboard behavior, scrolling, and smaller screens.
- Reuse existing designs and components where appropriate.

Do not invent unnecessary screens or redesign approved interfaces without authorization.
